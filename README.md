# Exercícios de lógica de programação em Portugol

Este repositório reúne os exercícios e algoritmos desenvolvidos durante a minha introdução à programação e ao raciocínio lógico.

O material utiliza o Visualg (portugol) como ferramenta de apoio no aprendizado dos conceitos fundamentais de desenvolvimento de software, abrangendo estruturas condicionais, laços de repetição, vetores e resolução de problemas matemáticos e lógicos.
